## 参考与实现

录屏 1080×1548 / 50fps / 7.1 秒。观察 2–7 秒菜单：小幅双轴偏移、圆角面板轻微伸缩、文字与面板整体运动、释放后归位。录屏没有触点位置，无法从像素反推出手指位移或精确弹簧参数，因此下列值是实现近似，不能声称逐像素复刻。

PDF 主菜单（含内联阅读方式/阅读界面）使用 Compose 长按拖动识别：18dp 渐近位移上限、1.2% 拾起缩放、最高 2.5% 方向伸缩；松手及取消回弹，阻尼比 0.72 / stiffness 380。短按沿用原功能。检测容器固定，菜单材质与文字整体移动；Backdrop 自身 layerBlock 负责缩放补偿，稳定动画 lambda 不每帧重建材质修饰器。拖动及回弹时不更新二级来源行坐标；进入二级/关闭过程禁用拖动。二级正文滚动和输入行为沿用原实现。

[Apple HIG / Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views) 明确软边缘使用渐变模糊分离滚动内容和悬浮控件，不应像覆盖层一样遮挡或压暗内容，每个视图仅使用一个边缘效果。

现有 Backdrop 2.0.0 提供固定半径模糊，没有空间可变模糊 API。底部 144dp 加系统导航 inset 范围内平滑叠合 2/8/20dp 三档真实模糊，属于 Android 12+ 的可变模糊近似。采用已验证的分级高斯采样控制文字混叠，透明端无硬边，不叠黑/白染色遮罩。采样图为页面 → 软边缘 → 胶囊底栏，不包含回环；沿用项目唯一 GlassBackdropSource 捕获边界。底栏采用 32dp 胶囊角和滑动选中背景，四个导航项、路由权威、RTL 与触摸行为保留。
