# 底栏改用PDF控件材质 — 2026-10-12

> 历史70版：用户随后指出强色散、采样不等比与上下折射范围不足，71版按新截图调整，见[当前报告](DOCK_SUBTLE_DISPERSION_20261013.md)。

用户反馈“为什么按压后面板会变白？然后材质换成pdf控件的试试，我看看效果，透镜的效果已经很不错了”。本轮只更换底栏面板材质并取消整栏按压增强，保留69版透镜效果。

## 根因与实现

69版没有给整栏增加按压白色填充，底色也保持不变；但Dock按压配方把边缘折射从0/0提升到24dp/24dp，高光从.28提升到.70。整条面板的折射带大幅变宽，采到附近的浅色页面内容，高光同时加强，造成按压后泛白。此前“远端中心颜色不变”的单点测试避开了折射带，不能证明整块面板材质稳定。

70版把`LiquidGlassStyle`中Dock直接并入PDF Control/Capsule的同一分支，删除旧Dock单独配方：4dp模糊、浅色白色32%、深色#242424 22%、8dp/24dp折射、.60边缘高光、相同阴影和vibrancy。实际PDF控件自身的按压提亮保持；Dock取消整栏按压色彩及高光增量，折射参数按住与静止一致，避免照搬PDF单按钮按压时的#AAAAAA/40%提亮到整条底栏。

透镜仍使用69版单次10dp/14dp色散、真实前景局部1→1.2倍放大、47dp材料光学采样、速度形变及回弹。`OpticalDockTabs.kt`、`GlassDock.kt`及`HomeDesignTokens.kt`与69版已验证源文件SHA256相同，见`retained-lens-geometry.json`。原导航、中央导入、单份实际前景捕获和数据库Room17保持；无依赖或shader新增。
