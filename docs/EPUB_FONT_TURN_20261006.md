# EPUB 翻页恢复与本地字体

用户要求恢复纸页翻页、增加外部字体导入，并修复 EPUB 菜单 / 目录开关闪烁；随后明确要求修好直接打正式包、停止模拟器测试。本轮仍使用 Readium 3.3.0 的唯一 Publication / Navigator，不恢复退役的原生文字分页器。正式产物为 1.0.0 / 46，Room v15；构建结果与最终摘要在完成后补充。

## 实现

- 翻页：PixelCopy 保留同一 Readium 页面已渲染的全窗口原页，SDK 准备目标页；上下层纸页执行覆盖动画，底页跟随四分之一位移。书名、正文及页脚一起移动，圆角读取 WindowInsets 的物理像素。渐进提亮只改变纸底，图像 / SVG 区域及文字像素保留。
- 位置：拖动捕获开始即冻结保存，依据当前 DOM URL 匹配 WebView，等待 Chromium 与原生滚动一致。停稳后同步提交已准备好的 Locator，避免第二个延迟保存与快速后续操作竞争。取消时仍由同一 Navigator 恢复原 Locator，原页覆盖到恢复完成；离开未提交手势时不写目标页。
- 字体：设置和 EPUB / Markdown 阅读设置提供“导入 / 管理字体”。SAF 选择后复制到私有 `reader-fonts`，校验 TTF / OTF 签名及 Android 原生字体解析，最大50 MB；按 SHA-256 去重，名称 / 后缀用 AtomicFile 保存。导入后选用，持久化只保存内容ID；外部源文件删除不影响私有副本。移除当前字体先清选中ID再移除资源，恢复此前默认 / 内置字体。PDF仍使用原文档字体。
- EPUB 字体通过 Publication 的本地 Resource 及 CSS FontFace 加载；不增加网络权限。Markdown 正文与表格测量使用同一 FontFamily，代码保持等宽。
- 菜单：旧关闭路径把 `settingsVisible` 清为false后，标题立即变成目录，Crossfade也启动设置到目录的切换；与此同时内容、遮罩与卡片各自结束不同动画。改为保留关闭前的分段与内容，以同一个280ms展开进度控制遮罩、面板内容和选中块。快速中断展开也保留内容，遮罩持续拦截到实际收起。分段切换直接更换内容，不叠加两份面板。原生 WebView 移出 Compose backdrop 的捕获层，玻璃顶部控件只采样稳定纸底，伸缩卡片使用同配方的直接材质绘制。
