# MarkLeaf v0.1.0-alpha

## 版本定位

这是墨阅 MarkLeaf 的第一个 MVP alpha 版本，面向 Android 本地 Markdown 阅读场景。

## 已支持

- 本地 .md / .markdown / .txt 导入
- 最近阅读列表
- 阅读进度保存与恢复
- Markdown 基础渲染
- H1-H6 标题
- 段落 / 加粗 / 斜体 / inline code
- 引用块
- 无序列表 / 有序列表
- 分割线
- fenced code block
- Kotlin / Java / Python / JavaScript / JSON / XML / Bash / Markdown 基础语法高亮
- 代码块复制
- 当前文档搜索
- TOC 目录跳转
- 阅读显示设置：字号、行高、页面边距
- Markdown 表格
- asset:// 内置本地图片显示
- content/file/http/https/相对路径图片安全降级
- 深色 / 浅色主题
- 无 INTERNET 权限
- 无 WebView
- 无广告、无统计、无账号、无同步

## 已知限制

- 当前为 debug APK，未做正式签名
- 相对路径图片暂不支持真实加载
- 网络图片禁用
- 不支持编辑 Markdown
- 不支持多端同步
- 不支持账号系统
- 不支持分享/社区
- 不支持文件夹文档库
- 大文件策略仍需后续专项优化
- 图片点击放大暂不支持
- 文档内链接点击暂不支持

## 隐私说明

本版本不申请 INTERNET 权限，不上传用户文件，不包含广告 SDK、统计 SDK、账号系统或同步逻辑。用户文件仅通过系统文件选择器授权后在本机读取。
