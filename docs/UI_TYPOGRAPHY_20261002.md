# UI 与排版优化

用户目标：先优化现有 UI、排版。保留离线阅读范围与既有简洁风格。

## 改动

- 首页品牌 22sp；继续阅读标题 20sp SemiBold；最近阅读分组 15sp。文件列表标题 16sp/24sp，图标区 36dp，增加标题与进度间距。
- 文库、设置页采用统一 headlineSmall；版本文字使用完整语义色，改善辅助信息对比度。
- 文库分类与阅读设置改用 FlowRow，阅读设置内容可滚动。
- Markdown 与 EPUB 使用同一正文 16.5sp、标题 24/21/19/17/16sp；行高仍由用户设置控制，不更改持久化设置值。
- EPUB 标题通过行样式控制层级，不叠加强制 Bold span；代码块使用独立字号与行高。
- EPUB 底部按两行页脚的实际测量高度预留空间，包含系统字体缩放及字体内边距；工具栏隐藏时仍保留两行布局，显隐不改变阅读区高度。
- PDF 页面是固定版式，本轮不重排 PDF 正文。
