## 需求描述（用户原话归纳）

当前页（节）应显示在当前章下面。例：第五章 → 第六节（当前）。顶部固定为当前章标题，下方为该章的节列表；**节列表拥有独立滚动区间**：手势先滚节列表，触顶/触底后再带动外层章列表滚动。

```
┌─────────────────┐
│ 第五章 ……        │ ← 固定头部（当前章）
│ ├ 第六节（当前）  │ ← 节列表独立滚动区
│ ├ 第七节         │
│ └ 第八节         │
├ 第六章 ……        │ ← 外层章列表
├ 第七章 ……        │   节触界后联动滚动
```

## 技术备注（供实现参考，非承诺）

- 嵌套滚动：`NestedScrollConnection` 连接节列表（内层）与章列表（外层），内层触界后剩余速度/位移交给外层；
- 当前章/节定位：依赖现有 outline 数据源与教材页码绑定状态，滚动时同步高亮；
- 与 `OutlineAdvancedContent` 现有平铺结构的关系：替换而非叠加（不留旧路径）；
- 验收：交互契约测试 + 实机人工验收。
