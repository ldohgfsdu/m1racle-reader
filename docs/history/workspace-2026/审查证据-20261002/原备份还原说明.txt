  git clone m1racle-reader-git-bundle-1.0.0-20261002.bundle M1racleReader
  cd M1racleReader
  git log --oneline -1          # 应显示 e175051

第三步 取回全部归档分支与 5 个历史恢复 stash：
  git fetch origin 'refs/tags/archive/*:refs/tags/archive/*'
  git fetch origin 'refs/stash:refs/stash'
  git tag -l 'archive/*'              # 5 个历史分支 tip + 5 个 stash
  git log --oneline refs/stash        # 2026-09-05 的工作区清理 stash

第四步 推到你自己的远端（这一步需要你决定推到哪）：
  git remote add mine <你的仓库地址>
  git push mine master --tags

构建这个项目需要的东西（bundle 里不含，需要另外准备）
────────────────────────────────────────────────────────
- JDK 17（AGP 9.1.1 + Gradle 9.5.0 要求；JDK 25 不能用）
- Android SDK：platform 37、build-tools 36.0.0
- local.properties 里写 sdk.dir（本机路径，故意没有进仓库）
- 正式签名材料：M1RACLE_RELEASE_STORE_FILE / _STORE_PASSWORD /
  _KEY_ALIAS / _KEY_PASSWORD 四项环境变量。当前 keystore 在原设备内部存储的
  M1racle Reader/keystore/m1racle-reader-release.p12，口令在同目录 password.txt。
  ⚠ 这些口令只存在于那台设备上，没有远程备份 —— 这是目前最需要补的一项。
- Gradle 依赖需要联网（settings.gradle.kts 里配了阿里云镜像优先）

测试：./gradlew :app:testQaUnitTest
在 aarch64 机器（如本机的 Termux/proot）上会有 2 项 ReadingRepositoryTransactionTest 失败，
原因是 Robolectric 的 SQLite 原生库不支持 aarch64，与代码无关；换 x86_64 机器即通过。
