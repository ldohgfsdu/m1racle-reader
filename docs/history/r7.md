==================================================
三、统一焦点保持数学
==================================================

缩放前先固定手指焦点对应的统一文档坐标。

概念上：

documentFocusX =
    (centroidX - viewportContentLeft + scrollX) / oldScale

documentFocusY =
    (centroidY - viewportContentTop + scrollY) / oldScale

应用 newScale 后：

newScrollX =
    documentFocusX * newScale
    - (centroidX - viewportContentLeft)

newScrollY =
    documentFocusY * newScale
    - (centroidY - viewportContentTop)

然后使用同一份新 geometry 做一次 clamp。

必须结合项目真实坐标模型实现，不能机械复制公式，
但必须满足不变量：

同一帧 scale 更新前后，
手指 centroid 下方对应的 document coordinate 保持不变。

禁止通过：

- currentPage
- pageIndex
- restore position
- Lazy/Pager item
- scrollToPage

间接维持缩放锚点。

缩放必须直接作用于统一 document transform。

==================================================
四、单一手势事务
==================================================

一次从第一根手指按下，到最后一根手指抬起，视为一个 transaction。

建议状态：

enum class ContinuousInteractionPhase {
    IDLE,
    DRAGGING,
    PINCHING,
    SETTLING
}

transaction 至少持有：

- gestureId
- baseScale
- currentScale
- baseScrollX
- baseScrollY
- focalDocumentX
- focalDocumentY
- lastCentroidX
- lastCentroidY
- pointerCount
- startedPageIndex

要求：

1. 双指开始时基于当前真实 transform 建立一次 baseline。
2. 后续每帧只在该 transaction 内更新 scale/scroll。
3. 不能每帧根据 currentPage 或 geometry 重新选锚点。
4. pointer 数量变化不得结束旧事务并从过期状态重启。

==================================================
五、pointer 数量变化
==================================================

重点修复：

- 1 → 2
- 2 → 1
- 2 → 3
- 3 → 2

规则：

1. pointer 数量改变时，以当前已显示 transform 为基准原子 rebase。
2. rebase 前后画面位置必须连续。
3. 2→1 后允许剩余一指继续平移。
4. 不能在 2→1 时执行 settle。
5. 不能在 2→1 时恢复旧 anchor。
6. 只有最后一根手指抬起后才能进入 SETTLING。
7. 同一 gestureId 只允许最终提交一次。

==================================================
六、松手与 settle
==================================================

最后一根手指抬起时：

1. 保留当前视觉 transform。
2. clamp 到合法范围。
3. 不调用 startup/mode-switch restore。
4. 不生成 page jump。
5. 不用 VM currentPage 反向定位 viewport。
6. 不重新按页面中心计算 anchor。
7. 不恢复 gesture 开始前的 scroll。
8. 不重复应用最后一帧 scale delta。
9. 只提交一次最终 stable scale/scroll/page。
10. debounce 后正常保存阅读位置。

若 scale 回到 1×：

- 只做从当前 transform 到合法 fit transform 的连续收敛。
- 不允许瞬间跳到当前页顶部或页面中心。

==================================================
七、geometry 与 clamp
==================================================

同一 transform update 必须严格按一个确定顺序：

1. 读取旧 transform。
2. 计算 focal document point。
3. 计算 newScale。
4. 用 newScale 得到新 geometry。
5. 根据 focal point 计算 newScroll。
6. 对 newScroll 做一次最终 clamp。
7. 原子发布 scale + scrollX + scrollY + geometry generation。

禁止：

- 先用旧 geometry clamp，再用新 geometry clamp。
- 多个 LaunchedEffect 分别修正 scale 和 scroll。
- geometry 更新后再根据 current page 自动定位。
- 每次 geometry 变化重新消费 restore。
- page tracking 回调反向改变 transform。

==================================================
八、interaction transaction 的视觉稳定
==================================================

PINCHING 和短暂 SETTLING 期间：

- 保持当前 composed page set 稳定。
- 保持 displayed Bitmap identity 稳定。
- 新 render 结果可进入 pending，但不要在手势中途频繁替换。
- 不因中心页变化立即回收仍可见 bitmap。
- 结束后统一计算一次最终可见页和 quality 请求。

本轮不重构 render queue，只实现最小冻结和最终一次提交。
