## 实现

废弃逐行改变采样半径的自算双向高斯核。其垂直过程会取到已使用不同水平半径处理的相邻行，文字的一次模糊不是一个稳定高斯核；本轮改由平台原生 `RenderEffect.createBlurEffect` 处理同一份正文，按固定深度连续混合不同模糊尺度。只用小型着色器计算连续权重和填补视口外页面色，不再自算模糊采样。没有新增依赖。

五个原生尺度按同一正文输入生成，权重总和为1，以预乘颜色相加。下缘最后回到原始正文；不以二次透明遮罩混入清晰底图。仍保留固定范围和按钮独立收起，搜索不改正文位置。顶部采样继续使用实际页面底色补足，避免把离开视口的笔画拉伸成闪动；记录区域留足原生高斯尾部并采用整数像素边距。

平台方法依据：[Android RenderEffect 官方文档](https://developer.android.com/reference/android/graphics/RenderEffect)。API33及以上完整光学路径替换旧实现，API31–32既有平台降级不扩大本轮验收范围。
