# 底栏 iOS 通透度与按压放大

用户补充 iOS / Google 底栏对比图，并明确选择“左侧 iOS：更通透，内容透过玻璃可见”；随后提供 `14a26d9510630df3ffa3e43fb7ff60d5.mp4` 并指出按压放大偏小。本轮同时调整 Hub 底座 / 独立加号的静态材质，以及选中透镜内图标 / 标签的按压尺度。弹簧跟随、释放吸附及取消复位保留。

## 调整与验证目标

原 Dock 白色 / 深色染色 alpha 为 0.56 / 0.60，边缘高光 alpha 0.60。真实页面采样已经接通，但覆盖偏重，降低了背景颜色变化在底栏中的可见度。新配方染色 alpha 为 0.18 / 0.26，高光为 0.24 / 0.28，阴影为 0.08 / 0.20；保持 8dp 模糊、1dp 预过滤和 12dp / 16dp 折射。

在真实 Android 窗口里切换暖色和冷色背景，对三个非选中入口无图标间隙测量传递的颜色差异；要求浅色保留超过 70%、深色超过 64% 的源颜色变化。改动前两项测试均失败，测得首个间隙浅色 0.5157479、深色 0.47047284；原始结果已归档。这是暖 / 冷源颜色差异的传递比例，不是对材质物理透光率的测量。原有细密背景模糊、光学折射、图标清晰度和取消过渡断言不放宽。本轮不改导航、手势提交规则、数据库、阅读器及分段控件配方。

## 新视频的按压反馈

新视频为 720×1024、30fps、32.17s 的 Books 窗口底栏。完整序列和 5–12s 底栏原始分辨率帧在本机提取，能看到图标 / 标签随按压放大、透镜外扩及拖动拉伸；上一轮参考的是 Photos / Books 横排文字控件，所选尺度偏小。

选中透镜由横向 1.20 / 纵向 1.28 改为 1.38 / 1.44；内部图标和标签由 1.12 改为 1.22，光学采样和直接前景共用同一规则。这些是本项目适配尺度，不是对视频的精确测量值。底座自身微抬起、独立加号按压、折射参数及弹簧不变。速度仍按绝对值对称拉伸，静止回到 1.0，释放 / 取消不能留下形变。

按新尺度平移断言端点、保持容差宽度后，旧实现单测 19 项中两项失败，模拟器像素检查一项也在旧尺寸上失败；失败结果分别保存在 `press-red-unit/` 和 `press-red-device/`。最终测试同时检查透镜尺寸、直接前景图标尺寸、真实光学蓝色笔画面积增加及取消后的原始尺寸。
