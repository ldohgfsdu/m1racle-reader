# Markdown 当前页编辑模式与顶栏撤销重做

2026-10-24。工作树 `reader-audit-fixes-20261024`，基线 615ded1，保留 F01–F10 及 Note 编辑引擎修复。原 reader 工作区保持原有改动；本轮没有提交、推送或公开发布。

## 当前操作

阅读页直接点顶栏铅笔「编辑正文」，在当前阅读 destination 内进入编辑模式。保持原标题，按当前段落对应的源码行定位；不创建独立编辑路由。直接点击正文输入，底部「正文/源码」切换；顶栏依次为撤销、重做、完成。完成成功提交后原地回阅读；未保存退出先确认。导出及授权原文件写回在底部更多中。

Home/文库的编辑入口同样进入 viewer 的编辑模式。独立 Markdown 可用，资源包需先导出为独立 Markdown。普通完成保存书库副本，授权写原文件需显式选择原文件。

## 实现

- 删除 `MARKDOWN_EDITOR` 独立路由及其导航和返回通知路径，阅读页内部维护模式。
- 保留原生阅读组件及 LazyListState，编辑时隐藏其视觉与无障碍节点；完成后更新数据，不先切 Loading，也不重建阅读位置。
- parser 提供每个块的原始行号，避免通过重复段落文字猜位置。修正注释跨 CR/LF 时行号被合并的问题，原始 Markdown 不重写。
- 目的地持有编辑 VM 子 store，旋转时保留文字；明确结束编辑后清理，防止下一次进入显示旧 VM 内容。
- 清理 owner 时完成最后一个草稿快照；先等旧 AtomicFile 写入结束再写新快照。放弃修改清掉最终快照，避免草稿复活。
- 完成操作统一由 VM 确认保存：无修改直接结束；保存期间收到后续输入则留在模式内并说明仍有未保存修改。
- 编辑模式下关闭目录滑出手势；外部打开沿用当前目的地编辑状态等待机制。
- 按用户最后要求将撤销/重做移至编辑顶栏，删除底部重复入口；底部正文/源码居中，更多选项靠右。
