## 交互与材料观察

- 已记录1800ms按住、1400ms全轨道慢拖、300ms快速反向、四入口点击切换、中央动作按压，以及10次500ms左右拖动。
- 按住：透镜高光、折射边缘、图标/标签放大，以及整条底栏轻微扩张共同出现。
- 移动：透镜形状随运动改变；通过中央动作位置时仍能看见底层加号经透镜折射。透镜内外图标呈现不同颜色和尺度。
- 松手：透镜缩回当前入口，玻璃高光/折射状态回到静止样式。录屏保留连续帧用于后续拟合，未仅凭30fps录屏宣称精确弹簧阻尼、刚度或输入延迟。
- 静止材料会透出实际页面色彩与文字；按压后折射和边缘色散更明显。可见选中与中央动作使用青绿色，未选中图标/文字接近白色。
- 中央按钮释放打开FeedEntranceV16Activity，已退出回到MainActivity；没有填写或发送内容。
- 额外保持DOWN、移动至数码后再UP的实验已存截图。正文区在该次语义树中没有可访问文本，held-navigation.json中的文本相等结果不构成导航提交时机的证据；不据此断言正文在拖动中或松手后切换。

10次500ms左右拖动，gfxinfo记录3008帧：P50 12ms、P90 15ms、P95 17ms、P99 19ms；GPU P95 10ms。新版Janky口径0%，legacy口径24.34%，两者不能混用。此数据包含整个酷安窗口、页面内容与切换，不能当作底栏单组件耗时，也不能与Reader的不同页面场景直接做性能优劣比较。

本次数据不包含内部模糊半径、折射公式、准确alpha或弹簧源码参数。这些不能仅靠截图、录屏和语义树唯一反推出。

## 日间模式与上下滚动补充

日间采样通过系统`cmd uimode night no`切换，确认`mComputedNightMode=false / mCurUiMode=0x1e`且酷安实际呈现浅色界面。深色对照显式切到`night yes`，确认`mComputedNightMode=true / mCurUiMode=0x2e`并检查截图。两种模式分别录制60秒，包含2200ms慢滚、180ms快速滚动、反向滚动、滚动后静止、2000ms按住、1800ms全轨道拖动、250ms快速反向、再次滚动后按住。没有通过点击首页的“刷新”入口主动触发刷新。

| 观察项 | 日间模式 | 深色模式 | 复刻要求 |
|---|---|---|---|
| 静止尺寸与滚动后位置 | 仍为1090×182px，56dp高；48dp透镜 | 相同 | 两套主题共用几何，不能因主题改变尺寸 |
| 上下滚动 | 所采样过程底栏保持原位、可见，未观察到收起或缩短 | 所采样过程同样保持可见 | 页面滚动持续刷新底栏的背景采样，不添加此次未见的滚动隐藏逻辑 |
| 材料底色与描边 | 白色半透明观感、亮白描边、软阴影 | 深色透明观感、灰亮描边 | 随主题替换材料参数，不能只更改图标颜色 |
| 背景穿透 | 字、图片和青绿色内容经过底栏后呈模糊亮斑 | 内容经过后呈模糊暗色/有色斑 | 采样真实正文；固定颜色渐变无法复现滚动中的变化 |
| 选中区静止 | 较深的半透明灰色胶囊，绿色图标和标签 | 较亮的半透明灰色胶囊，青绿色图标和标签 | 静止选中填充与按压透镜的材料分开描述 |
| 按住 | 透镜放大、内容折射、边缘有彩色分离；整条底栏略扩张 | 同类响应，彩色边缘在暗背景下更突出 | 整条底栏扩张、透镜放大、运动形变和松手回弹共同参与 |
| 屏幕底部 | 正文在底栏及系统手势附近逐渐淡向浅色背景 | 正文逐渐淡向深色背景 | 保留底部渐淡层，不能只绘制一个玻璃胶囊 |
| 未选中入口 | 黑色图标和文字 | 白色图标和文字 | 保持前景清楚，透镜内则跟随选中/折射状态 |

日间静止、滚动后和最终主页的语义坐标，与最初深色样本一致，见`theme-scroll-geometry.json`。录屏观察显示，日间首页入口在部分滚动/页面状态中短暂呈现圆形刷新图标与“刷新”文字，随后恢复“首页”；触发条件未单独隔离，不能宣称它仅由某一滚动方向决定。该状态属于首页业务联动，是否映射到Reader需结合Reader现有页面行为。

当前Reader与参考的可见差距按优先级记录：

1. 基础高度64dp/透镜56dp偏大，应以参考56dp/48dp作为尺寸对齐依据；按住约66.5—67dp。
2. 当前整条底栏主要横向位移，参考还有约5%的宽度扩张，需配合透镜形变。
3. 日间白色材料、选中静止灰层、按压折射和底部渐淡需要分别校准。
4. 滚动时的真实背景采样及彩色内容穿透要在文字、图片两类背景下验收。
5. 弹簧和折射参数需要用连续帧校准；这些观测不是源码参数，也不构成Reader已复刻完成的证明。

本次为参考采集，Reader仍是此前安装的Release54；没有据本次采样新建Release或宣称上述差距已经修复。

## 详情页玻璃按钮与悬浮加号

按用户确认，补充采样对象为“小米17 Pro”详情页底部的对比、已关注、打分、购买玻璃按钮组，以及右侧悬浮加号，不扩展到开关、滑杆等通用控件。深色与日间分别录制30秒；每个控件单独DOWN、保持、移出原点击区域再UP，记录按压与释放，避免改变已关注状态或进入购买流程。所有点击位置从实际UI树获取。

| 项目 | 语义坐标 / 大小 | 换算与说明 |

| 四按钮交互区 | [85,2430]—[227,2586]；[227,2430]—[368,2586]；[368,2430]—[493,2586]；[493,2430]—[649,2586] | 高度156px =48dp；宽度随标签不同，不是四个等宽tab |
| 四按钮图标语义框 | 每个72×72px | 约22.15×22.15dp，不等于图形实际墨迹大小 |
| 浮动加号 | [995,2428]—[1155,2588]，160×160px | 约49.23dp直径；与左侧胶囊垂直居中对齐 |
| 加号图形语义框 | [1030,2463]—[1121,2554]，91×91px | 28×28dp；中心与按钮中心基本一致 |
| 按住左侧任一按钮 | 截图整组外缘约x40—690、y2422—2594 | 约650×172px，宽高相对静止约增加7—8%；为近似视觉边缘，未作为精确实现常量 |
| 按住加号 | 截图圆形外缘直径约174px | 约53.5dp，相对静止放大约9%；近似视觉值 |

这组动作按钮与首页导航的材料响应不同：

- 按住一个动作按钮，**整块胶囊**扩张、材料亮度提高，内部图标文字保持其各自入口；没有观察到像首页那样随入口移动的独立选中透镜。
- 深色静止胶囊透出正文图片的暗色与亮斑，按住后整体更亮、更偏灰；日间按住后呈亮白材料、白描边与软阴影。背景来自实际图片，不能换成固定渐变。
- 四个入口都是动作按钮；“已关注”的绿色心形和文字属于既有业务状态，不能当成当前导航选中状态。
- 加号独立放大并变亮，边缘高光加强；按压加号时左侧胶囊保持自身静止材料。深色样本为青绿色圆形/深色加号；日间样本为绿色圆形/白色加号。
- 释放后控件恢复静止外观；录屏保留过渡，未凭离散截图推断准确回弹阻尼或时长。
- 实际点击加号打开带背景遮罩的发布入口面板。有效日间面板语义边界为[0,1329]—[1220,2656]，顶部圆角，内含动态、点评、图文、续航、跑分、样张、反馈、视频、二手。仅打开观察，未选择入口或提交内容。BACK后详情页也离开了，因此后续标为dark/plus-open的截图实际为首页，不用作深色面板证据；深色加号静止/按压证据仍有效。

复刻时，动作按钮组应使用共同的按压扩张与材料反馈；悬浮按钮保持独立反馈；业务动作、状态颜色与导航透镜分开。此处记录的是参考行为，未向Reader添加对比、关注、打分、购买或发布功能。
