用户提供 `5b0adb82ac44cd7f179d5c8736554bee.mp4`（28.03s）和 `51afe3b257cd40e46ff3ea1c2ca08fc1.mp4`（20s），均为 720×1024、30fps。本轮直接在本机提取完整序列和 15fps 控件区域帧，参考视频内的 Photos / Books 玻璃控件行为；没有将私人视频上传至外部服务。

## 参考观察与实现

参考中的静止选中块柔和、玻璃底座偏白；触下时选中透镜移到手指所在项、灰色覆盖退去并出现折射 / 边缘高光；拖动会拉伸和恢复；松手后归位。背景滚动时玻璃继续采样下方内容。参考是横排文字控件，本项目保留四个图标 / 标签及独立加号，将这些材质和运动行为应用于底栏。

原实现按住未选中入口只放大旧选中块，拖动用零时长动画直接跟手，速度正负还导致相反的长宽变化。本轮：

- 按压与拖动使用同一预览位置，导航所有者仍决定真实选中项。触下先显示目标项的蓝色采样图标，松手才导航，取消则回原项。
- 选中蓝色在光学模式下只由移动透镜绘制，前景图标统一使用非选中色；取消 / 松手回程也不会在原入口提前恢复蓝色，避免过渡帧重复高亮。设备像素回归冻结取消后 32ms，要求透镜之外的原入口没有蓝色像素。
- 去掉拖动 `tween(0)`，使用既有共享 pickup 弹簧跟随，释放使用 selection 弹簧吸附。保留单一位置状态与现有四入口导航链。
- 按压尺度为横向 1.20 / 纵向 1.28，采样图标 1.12；速度用绝对值形成对称横向拉伸 / 纵向收缩，松手残余速度不会改变最终静止尺寸。
- Dock 保留 8dp 模糊及 1dp 预过滤，染色 alpha 为浅色 0.56 / 深色 0.60，边缘折射 12dp / 16dp。选中块静止覆盖降至 0.08，按住时退去。阅读器及分段控件配方不变。
